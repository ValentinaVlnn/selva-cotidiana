# Selva Cotidiana Blog

## ¿Qué es este proyecto?

Este proyecto es una web de tipo blog desarrollada con HTML, CSS y Bootstrap. Presenta una propuesta visual centrada en plantas, bienestar y naturaleza, con una página principal y secciones secundarias de plantas, nosotros, galería y contacto.

## ¿Cómo se usa?

Para recorrer el sitio, abrí el archivo index.html en tu navegador y navegá desde el menú a las distintas secciones. No requiere inicio de sesión.

## ¿Qué necesita el usuario para ejecutarlo o contribuir?

Para ejecutarlo:

- Un navegador web actualizado.
- Los archivos del proyecto descargados o clonados en una carpeta local.

Para contribuir:

- Un editor de código como Visual Studio Code.
- Git instalado si se quiere trabajar con control de versiones y subir cambios a GitHub.
